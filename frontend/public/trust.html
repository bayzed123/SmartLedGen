Trust Center

What's actually true about how SmartLeadGen is built and run — not marketing copy.

Infrastructure

Runs entirely on Cloudflare Workers, with data stored in Cloudflare D1. All traffic is served over HTTPS.

Data isolation

Every stored record — users, API keys, jobs, leads — is scoped to a single account. There is no code path that lets one account query another's data; the only exception is the operator's admin view, used strictly for support and system health, not for reading individual API key values.

API key security

Every API key you add is encrypted (AES-256-GCM) before it's written to storage, using a key that never leaves the server. Keys are decrypted only in memory, only at the moment a search or chat needs to call that provider, and are never sent to your browser after the initial save.

Passwords

Account passwords are hashed (PBKDF2, 100,000 iterations) — never stored, logged, or visible in plain text, including to us.

What we ask of you

Treat your own API keys and account password the way you'd treat any other credential — this product only ever asks for them through its own secure form fields, never through email, chat, or any other channel.
