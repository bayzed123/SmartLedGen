Getting started

  • Sign up, then add your Google Places API key (required) — get one via Google Cloud, making sure "Places API (New)" specifically is enabled.
  • Optionally add one AI provider key (Gemini, OpenAI, or Claude) if you'd rather describe a goal in plain words than type a keyword and location.
  • Run a search — leads appear live as they're found, with a High/Medium/Low opportunity score.

Common errors

"Google rejected this request (403)" — usually means Places API (New) isn't enabled on your Google Cloud project, or billing isn't enabled on that project. Both are needed even for light usage.

"Rate-limited by Google (429)" — you're calling faster than your project's quota allows. Wait a bit and try again, or raise your quota in Google Cloud.

"insufficient_quota" (OpenAI) or "quota exceeded" (Gemini/Claude) — this is the AI provider's account, not SmartLeadGen. Gemini has a free tier but a low per-minute limit; OpenAI and Claude generally need a payment method added on their own site before any call works.
