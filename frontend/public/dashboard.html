API keys

Two keys serve two different jobs — see below for which one you actually need.

Why two API keys?

Google Places API is Google's own directory of real businesses — name, address, phone, website, rating. It's the only reliable way to find real leads, which is why it's required. An AI model alone can't do this reliably; it doesn't have a live, verified list of businesses. Note: this is a different Google product from "Maps JavaScript API" (which just displays a map on a page) — when creating your key in Google Cloud, check that Places API (New) specifically shows as enabled, not only "Maps."

Gemini / OpenAI / Claude (pick one, optional) doesn't find businesses — it understands plain-English text. Add one only if you'd rather type a goal like "marketing clients in Dhaka with no website" instead of a keyword and location, or want it to draft outreach emails once that feature ships. Skip it entirely if you're happy typing keyword + location yourself.

Getting a "quota exceeded" or 429 error the first time you use a key? That's the provider's account, not this app: Gemini has a real free tier (via aistudio.google.com) but a low per-minute rate limit — wait a minute and retry. OpenAI and Claude generally require adding a payment method on their own site before any call works at all, even a cheap one — there's no usable free quota to fall back on for those two.

Your keys are encrypted before they're ever stored — nobody but this account's jobs can use them.
