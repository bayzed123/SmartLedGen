How it works

Three steps, using data sources that actually exist — not guesses from an AI model.

01

Tell it what you're looking for

A business type and a location — "dentists in Gulshan" — or describe your goal in plain words and let AI turn it into a search.

02

It checks Google's own business directory

Real listings via Google Places API — name, address, phone, rating — then visits each website for a contact email and social links.

03

You get a scored, exportable list

Every lead is flagged High/Medium/Low opportunity based on how weak their online presence is. Export to CSV, or push straight to your Google Sheet.

Quick questions

Do I need to know how to code?

No. You'll need a Google Places API key (a free Google Cloud account, a few clicks — we link you straight to it), and that's it.

Is my data shared with other users?

No. Every account's leads and API keys are isolated — nobody else can see them, including us, since keys are encrypted before they're stored.

What if I don't want to add a Google Sheet?

CSV export works with no setup at all. Google Sheets is an optional convenience for auto-updating a shared sheet.

Where can I get more help?

Use the chat bubble in the corner, or visit the Help Center.
